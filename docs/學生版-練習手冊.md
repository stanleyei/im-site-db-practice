# 看畫面設計資料庫：資管系網站練習（學生版）

練習網站：<https://stanleyei.github.io/im-site-db-practice/>
資料庫：MariaDB（以 HeidiSQL 操作）　ERD 工具：drawSQL

## 這份練習在做什麼

你是這個系所網站的資料庫設計師。網站畫面已經做好了，但資料庫還不存在。
你的任務是**只看畫面**，反推這個網站背後需要哪些資料表、每張表有哪些欄位、表與表之間怎麼關聯，然後把畫面上看到的資料一筆一筆放進去。

最後用第三部分的查詢題檢驗自己的設計：**題目不會告訴你資料表叫什麼、欄位叫什麼**，只用「網站上的說法」描述要查的東西。設計合理，每一題都能查出和畫面一模一樣的結果；某一題查不出來或數字對不上，通常代表某張表或某個欄位的設計需要回頭修。

練習情境的「今天」固定為 **2026-09-16**，所有和「目前」「本月」「已過期」有關的題目都以這一天為準。

## 網站有哪些畫面

請把每個畫面都點開看過，包含右上角的「後台管理」。後台會顯示前台看不到的資料，這些是設計欄位的重要線索。

| 畫面 | 看什麼 |
|---|---|
| 首頁 | 置頂公告、最新消息、近期活動、熱門下載，這些區塊是怎麼「挑」出來、怎麼「排」的 |
| 最新消息 | 分類篩選（注意有一個分類是 0 則）、置頂、發布日期、點閱數、標籤、附件數 |
| 公告內文 | 一則公告的完整內容、附件清單（檔名、大小）、展示期限 |
| 下載專區 | 分類、檔案格式、大小、下載次數、更新日期 |
| 活動行事曆 | 起訖時間（有跨日活動）、地點、報名截止日（有的活動免報名）、已結束標記 |
| 師資介紹 | 職稱、行政職、研究室、分機（有人沒填）、信箱、專長、排列順序 |
| 系所相簿 | 相簿與照片的關係、封面、拍攝日期 |
| 常見問題 | 分類、順序 |
| 意見信箱 | 表單欄位 |
| 頁尾友善連結 | 分類、順序、是否另開視窗（有箭頭符號的） |
| 後台管理 | 已下架公告、無期限公告、公告編號、分類的公告數、標籤使用次數、隱藏的問答、留言處理狀態與回覆時間 |

## 第一部分：設計（drawSQL）

1. 逐個畫面列出「這個畫面需要儲存哪些東西」，再歸納成資料表。
2. 每張表決定主鍵、欄位名稱與**資料型別**。看到日期就想 DATE 或 DATETIME，看到數量就想整數，看到「是／否」就想布林值，看到固定幾種狀態（例如留言的處理狀態）就想查找表，和分類的處理方式一樣。
3. 畫出表與表的關聯線，標出一對多的方向。
4. 全站至少有一組「多對多」關係，找出來並用中介表處理。

自我檢查：

- 同一個名詞（例如分類名稱）會不會在很多筆資料裡重複打字？重複的東西通常該獨立成一張表。
- 一則公告可以有好幾個附件，附件該放在公告那張表裡，還是另外一張表？
- 畫面上顯示「1.3 MB」和「64 KB」，資料庫該存文字還是數字？存數字時單位要統一。
- 「免報名」「未提供」「無期限」在資料庫裡該怎麼表示？
- 「已結束」「已下架」「上架中」是要存進去的欄位，還是可以從其他欄位算出來的？

## 第二部分：建表與輸入資料（HeidiSQL）

1. 建立資料庫（建議名稱 `im_site`，字元集 `utf8mb4`）。
2. 依照 ERD 建立每一張表。
3. 把畫面上看到的**每一筆**資料輸入進去。資料量不大，共 18 張表左右、80 多筆，但請確實照畫面輸入，包含後台才看得到的那些。
4. 輸入時留意：空值該填 NULL 而不是 0 或空字串；日期時間請用資料庫的日期型別輸入，不要打成「9/24 下午 2 點」這類文字。

## 第三部分：查詢題

每題請寫出 SQL，執行後把結果和指定畫面比對。做完在最後的自評表打勾。

### A. 基礎查詢

**A1.** 列出「最新消息」頁面目前看得到的所有公告標題與發布日期，依發布日期由新到舊排序。已經下架的不能出現。（對照：最新消息）

**A2.** 首頁「最新消息」區塊的排序規則是「置頂的先，其餘依發布日期新到舊」。請寫出這個排序，取前 5 則。（對照：最新消息前 5 則）

**A3.** 列出標題中含有「招生」兩個字的公告。（對照：最新消息）

**A4.** 列出所有「已結束」的活動名稱。（對照：活動行事曆，「今天」是 2026-09-16）

**A5.** 列出下載專區所有 PDF 檔的名稱與大小，依大小由大到小。（對照：下載專區）

### B. 彙總統計

**B1.** 每個公告分類各有幾則公告？**沒有公告的分類也要列出來並顯示 0**。（對照：後台 › 公告分類管理）

**B2.** 每個標籤被用在幾則公告上？沒被使用的標籤也要出現。（對照：後台 › 標籤管理）

**B3.** 下載專區所有檔案的總容量是多少 KB？最大的檔案是哪一個？（對照：下載專區，自行換算）

**B4.** 每個下載分類的總下載次數。（對照：下載專區，自行加總）

**B5.** 所有公告的點閱數總和與平均值。（對照：後台 › 公告管理）

### C. 關聯查詢

**C1.** 列出附件超過一個的公告標題與附件數。（對照：最新消息的「附件 N 個」）

**C2.** 列出「轉學考招生簡章公告」的所有附件檔名與大小，大小以 MB 顯示並保留一位小數。（對照：公告內文）

**C3.** 列出每位教師的姓名、職稱名稱、研究室，依畫面上的順序排列。（對照：師資介紹）

**C4.** 每本相簿有幾張照片？封面是哪一張的檔名？（對照：系所相簿）

**C5.** 同時貼有「競賽」和「獎學金」兩個標籤的公告是哪一則？（對照：最新消息的標籤）

**C6.** 列出沒有任何標籤的公告標題。（對照：後台 › 公告管理，標籤欄顯示「—」）

**C7.** 頁尾「相關資源」分類下的連結，依顯示順序列出名稱與網址，並標示是否另開視窗。（對照：頁尾與後台 › 友善連結管理）

### D. 進階查詢

**D1.** 列出「目前仍在上架期間」的公告：已發布、而且下架時間還沒到或沒有設定下架時間。（對照：最新消息 7 則）

**D2.** 列出 2026 年 9 月的活動，並算出每場活動持續幾個小時。（對照：活動行事曆）

**D3.** 列出所有「還沒開始、而且需要報名」的活動名稱與報名截止日。（對照：活動行事曆）

**D4.** 列出尚未回覆的留言，依留言時間由舊到新。（對照：後台 › 留言管理）

**D5.** 已回覆的留言，從留言到回覆各花了幾小時？（對照：後台 › 留言管理，自行換算）

**D6.** 常見問題頁面只顯示「前台顯示」的問答。請寫出前台頁面的查詢：分類名稱、問題，依分類順序再依問題順序排列。（對照：常見問題）

### E. 異動操作

**E1.** 新增一則公告「115 學年度校外實習說明會」，分類為「就業實習」、不置頂、發布時間 2026-09-16 10:00、無下架期限、點閱 0，並附上兩個附件：「實習說明會簡報.pdf」2,300 KB、「實習合作企業名單.xlsx」45 KB。新增後重新執行 B1 與 C1，確認數字有變。

**E2.** 把 4 號留言「選課系統無法登入」標記為已回覆，回覆時間 2026-09-16 09:15。重新執行 D4 確認它消失。

**E3.** 刪除 3 號問答「人工加簽單要找誰簽？」。刪除後執行 D6 確認結果不變（因為它本來就是隱藏的）。

**E4.** 相簿「2025 系友回娘家」要整本刪除。請寫出正確的刪除順序，並說明為什麼順序重要。

「繞了遠路」的意思是：查得出來，但得用 LIKE 拆字串、用文字比大小、或手動把好幾個欄位加起來。這通常也是設計可以改進的訊號。

## 常見的「查不出來」對照

| 症狀 | 可能的原因 |
|---|---|
| B1 或 B2 列不出 0 的那一列 | 分類或標籤沒有獨立成表，只是公告裡的一個文字欄位 |
| C1 算不出附件數 | 附件被做成公告表裡的「附件一、附件二」欄位 |
| A1、A2 排序怪怪的 | 日期存成文字（如「2026/9/5」），排序變成字典順序 |
| B3、C2 無法加總或換算 | 檔案大小存成「1.3 MB」這種文字 |
| D1、D2、D5 沒辦法比較或相減 | 日期時間存成文字，或起訖時間塞在同一個欄位 |
| C5 做不出來 | 標籤用逗號串在一個欄位裡 |
| A4 的「已結束」、D1 的「上架中」找不到欄位 | 這些不是欄位，是用今天的日期和時間欄位算出來的 |
| D4 抓不到「處理中」那筆 | 狀態表只有兩筆（沒有「處理中」），或把「有沒有回覆時間」當成唯一判斷 |
